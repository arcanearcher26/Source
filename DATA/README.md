# DATA — game data and extracted references

Use this folder for data, not executable source or release JARs.

Examples:
- Item ID tables
- Option ID tables
- NPC/shop data
- map/skill/event data
- RMS/save-state notes
- extracted resource inventories
- version manifests
- checksums

Every dataset should record its source version and extraction method. Runtime data from 25.47 must not be silently mixed with 25.27 data.
