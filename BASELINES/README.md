# BASELINES — clean game versions

This folder contains **untouched** game JARs received from the user/upstream.

Rules:
- Never patch these files.
- Never replace an older baseline with a newer one.
- Every version gets its own folder.
- Keep SHA-256 and source/date metadata beside the artifact.
